# Texas A&M CSCE694 — Physically Based Modeling HW1

Starter scaffold for the assignment.

## Setup
```bash
pip install -r requirements.txt
python src/main.py
```

## Controls
- `R` reset ball
- `ESC` quit

## Notes
- Physics integration and collision response are intentionally simple so you can extend them for the assignment.
- Rendering uses Pygame and math uses NumPy.
